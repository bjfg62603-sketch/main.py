# 🤖 SmertnyTeam Bot

Модерационный бот для автоматизации чатов с системой предупреждений и админ-панелью.

## ✨ Функции

- 🔇 **Мут** — замутить пользователя (`.mute` с ответом на сообщение)
- 🔊 **Размут** — снять мут (`.unmute` с ответом)
- ⚠️ **Варны** — выдать предупреждение (`.warn` с ответом)
- 🤖 **Авто-мут** — после N варнов пользователь мутится автоматически
- 📝 **Логирование** — все сообщения сохраняются в БД
- 🗑️ **Авто-удаление** — сообщения замученных удаляются мгновенно
- 🔐 **Админ-панель** — `/admin` для управления ботом

## 📋 Команды

| Команда | Действие |
|---------|----------|
| `.mute` (ответ) | Замутить пользователя |
| `.mute 10m` | Замутить на 10 минут |
| `.unmute` (ответ) | Размутить |
| `.warn` (ответ) | Выдать предупреждение |
| `/admin` | Открыть админ-панель |

## 🛠️ Технологии

- Python 3
- python-telegram-bot
- SQLite

## 🚀 Деплой

Бот запущен на Render.com
